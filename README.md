# 文脈工房 — 日本語文章スタジオ（ことばねUIベース）

AIが書いた下書きの定型表現や反復をチェックし、元の主張や引用を保ちながら人間らしい自然な日本語へ整えるPWAです。  
**Word（`.docx`）・PDF（`.pdf`）・テキスト（`.txt` / `.md`）** からの直接アップロードに対応しています。

## 公開URL
https://affksllkso.github.io/bunsho-studio/

## 主な機能
- **ことばねベースの洗練UI**: 左サイドバー（文章スタジオ／履歴／文体プロファイル）、ダークモード標準（ライトモード切替対応）、2カラム（原稿＋AI文体チェック）＋下部リライトワークスペース
- **Word / PDF / テキスト読み込み**: `.docx`（完全ローカル解析）・テキスト層付き `.pdf`（日本語CMap対応）・`.txt` / `.md` をボタンまたはドラッグ＆ドロップで読み込み
- **AI文体チェック（5指標＋詳細統計）**: 定型表現・接続詞・文末の反復・文長の特徴・文章構成の5指標スコア、本文ハイライト＋クリックで理由表示、文長分布・文末傾向などの詳細統計
- **自然な文章に整える（オフライン完結＋任意Gemini API連携）**: 大学生レポート（常体／敬体）・一般・学術・ビジネス・自分の文体プロファイルに応じた変換、変更度スライダー、引用保護、変換前後のスコア比較＆差分表示、Word / テキスト出力
- **履歴 ＆ 文体プロファイル**: 端末内ローカル保存、自作文からの文体傾向抽出
