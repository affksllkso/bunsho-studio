# 文脈工房 — AI文章判定＆自然文リライトPWA

AIが書いた文章かどうかを多角的に判定し、人間が書いたような自然な日本語へ変換（ヒューマナイズ）するPWAです。  
APIキー不要・完全ローカル／オフラインで動作します（任意で Gemini API キーを設定した高度リライトにも対応）。

## 公開URL
https://affksllkso.github.io/bunsho-studio/

## 主な機能
- **AI文章判定（0〜100%スコア＋6指標分析）**:
  - AI定型フレーズ密度（「〜と言えるでしょう」「重要な役割を果たします」等）
  - 構成の定型化（「まず・次に・最後に」「以上のことから」「結論として」等）
  - 翻訳調・冗長表現（「〜することが可能です」「〜の観点から」等）
  - 文長の均一性（Burstiness／変動係数CV）
  - 語尾の単調さ・連続率
  - 過剰なMarkdown太字・箇条書き装飾
- **AI箇所ハイライト**: 原文中のAIらしい表現を強度別に色分けし、理由をツールチップ表示
- **自然文リライト（ヒューマナイズ）**:
  - 変換強度（控えめ／標準／強め）と文体（元の文体を維持／です・ます／話し言葉寄り／だ・である）を選択可能
  - 変換前後のAIスコア改善幅（Before → After）を即座に再判定
  - 差分比較（Before / After）・変更ポイント一覧・別パターン再変換・履歴保存
- **PWA対応**: オフライン利用・ホーム画面インストール対応
