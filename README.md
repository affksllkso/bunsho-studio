# SCRIPT LAB

**Analyze, Refine, Rewrite.**  
文章の分析・リライト・文体学習を備えた日本語文章編集ツール（PWA）です。  
**Word（`.docx`）・PDF（`.pdf`）・テキスト（`.txt` / `.md`）** からの直接アップロードに対応しています。

## 公開URL
https://affksllkso.github.io/bunsho-studio/

## 主な機能
- **AI文体チェック（5指標＋TRAINING LAB 標準搭載モデル v1 連携）**: 定型表現・接続詞・文末の反復・文長の特徴・文章構成の5指標ルールベース判定に加え、[TRAINING LAB](https://affksllkso.github.io/training-lab/) で1,000件コーパス（GPT-6.2生成500件・人間執筆500件）から学習した文字2〜4-gram TF-IDF＋ロジスティック回帰モデル（`sl-20261127-151539-187855-f08f5034-5a80f92a-a70a24e9`、特徴量12,000件、しきい値51%）を標準搭載。オフライン・ブラウザー内で直接推論し、ルールとの併用・単独切替・特徴語確認・追加モデルのバージョン管理に対応
- **自然な文章に整える（オフライン完結＋任意Gemini API連携）**: 大学生レポート（常体／敬体）・一般・学術・ビジネス・自分の文体プロファイルに応じた変換、変更度スライダー、引用保護、変換前後のスコア比較＆差分表示、Word / テキスト出力（Gemini 4 Hydrogen / Neon 等に対応）
- **Word / PDF / テキスト読み込み**: `.docx`（完全ローカル解析）・テキスト層付き `.pdf`（日本語CMap対応）・`.txt` / `.md` をボタンまたはドラッグ＆ドロップで読み込み
- **履歴 ＆ 文体プロファイル**: 端末内ローカル保存、自作文からの文体傾向抽出
- **PWA対応**: TEXT LENS アイコン（192px / 512px / maskable 512px / 180px apple-touch-icon）、ダークネイビー `#101B26` テーマ
