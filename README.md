# 文脈工房 — Bunsho Studio

文脈を設計し、言葉を磨くための日本語ライティング＆推敲PWAです。  
ビルド不要・完全ローカル保存・オフライン動作に対応しています。

## 公開URL
https://affksllkso.github.io/bunsho-studio/

## 主な機能
- **文脈設計パネル**: 想定読者・目的・トーン＆マナー・核となるメッセージ・構成ブロック（アウトライン）を執筆画面の横で常時管理
- **集中執筆エディタ**: リアルタイム文字数／原稿用紙換算／読了目安、目標文字数バー、Markdownツールバー、集中モード（禅モード）、横書き／縦書きプレビュー切替
- **日本語推敲エンジン（オフライン完結）**:
  - 敬体（です・ます）／常体（だ・である）の文体混在チェック
  - 長文アラート（1文の文字数超過検出）
  - 語尾の連続検出
  - 漢字・ひらがな・カタカナ比率の可視化
  - 表記ゆれ＆カスタム用語ルール検出とワンクリック置換
- **版管理（スナップショット）**: 推敲前の状態を保存し、いつでも復元可能
- **データ管理**: 自動保存（`localStorage`）、Markdown / テキスト出力、JSONバックアップ＆復元
- **PWA対応**: ホーム画面へのインストール、Service Workerによるオフライン利用
