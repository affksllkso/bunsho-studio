SCRIPT LAB の使い方

  1. 原稿を用意する：テキストを直接貼り付けるか、「ファイルを読み込む」（またはドラッグ＆ドロップ）で Word（.docx）・PDF（.pdf）・テキスト を読み込みます。
  2. AI文体をチェック：5つの指標（定型表現・接続詞・文末の反復・文長の特徴・文章構成）でスコア化し、本文ハイライトで理由を確認できます。
  3. 自然な文章に整える：文体プリセットや変更度を選んでリライトを実行。オフラインでも即座に自然な日本語へ整え、差分比較・Word/テキスト出力ができます。
  4. 文体プロファイル：過去の自作文を登録しておくと、「自分の文体」プリセットで文体傾向を反映できます。

AI連携設定（Gemini / ChatGPT / Claude）

通常のチェック＆リライトはAPIキー不要・端末内完結で動作します。
API連携を使う場合は、利用するAIを選んでAPIキーを入力してください（キーはお使いのブラウザーの localStorage のみに保存されます）。
